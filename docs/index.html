How it works

It's a pocket for files mid-drag. No more holding the mouse button while you hunt for the right window.

  1. Start dragging

    Pick up one or more files from Finder, the Desktop, Mail or anywhere else you can drag from.

  2. Shake

    Move the cursor left and right a few times. A floating shelf appears right under it.

  3. Let go

    Drop the files on the shelf. They wait there while you open the folder or app they're headed for.

  4. Drag them out

    Drag from the shelf to the destination. Everything on the shelf goes together, and the shelf closes once the files land.

The destination decides what happens, just like a normal drag. Finder moves files on the same disk and copies them to another one. Hold Option to copy. Cancel the drag and the files stay on the shelf.

What else the shelf does

Everything runs on your Mac. The shelf only holds references, so nothing is ever deleted.

Drop on the notch

Not in the mood to shake? Drop files on the top centre of the screen, where the notch sits on newer MacBooks. It glows purple while you drag. You can move it to the left or right edge, or turn it off.

Act on every file at once

Right-click the shelf or use its ⋯ button for one menu that works on everything on it.

  • Share
  • Copy Path
  • Reveal in Finder
  • Compress
  • Move to Folder
  • Convert images
  • Resize images

Images convert to PNG, JPEG, HEIC or TIFF, or shrink to 75, 50 or 25 percent. New files land next to the originals and never overwrite anything.

Bring back a recent shelf

Recent Shelves in the menu bar keeps the last 10 shelves you cleared. Pick one to put those files back, even ones that have since moved. Anything that no longer exists is skipped.

See what you're carrying

The Files button at the bottom of the shelf opens a details panel with the total size, plus each file's size and the detail that matters for its type: pixel size, duration, page count or item count. Switch between grid and list.

Tune the shake

Shake Settings sets how far each stroke goes, how many direction changes count, the time window and a cooldown between shelves. Changes apply as soon as you save.

Prefer a text file? Edit ~/Library/Application Support/ShakeThat/settings.json.

Lives in the menu bar

Show Shelf, Clear Shelf, Shake Settings and Quit, all from one icon. Move the shelf by dragging its edge, and close it with ✕ whenever you like. Your files stay exactly where they were.

Install

Grab the app, or build it yourself with the Swift toolchain.

Download

  1. Download the latest zip from Releases.
  2. Unzip it and move ShakeThat to your Applications folder.
  3. Open it. The shake icon appears in the menu bar.

Opening it the first time

ShakeThat isn't signed with an Apple Developer ID, so macOS warns that it can't verify the developer. Right-click the app in Finder, choose Open, then confirm. You only do this once.

On macOS 15 Sequoia and later, try opening it once, then go to System Settings › Privacy & Security and click Open Anyway.

Build from source

Needs Xcode 15 or the Swift 5.9 command line tools.

$ git clone https://github.com/Ud7t/ShakeThat.git
$ cd ShakeThat
$ ./scripts/build-app.sh
$ open build/ShakeThat.app

Run it straight from SwiftPM with swift run, open Package.swift in Xcode, or run the tests with swift test.
